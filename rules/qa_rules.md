# AI-QA-Assistant｜WPS场景模拟质检规则 V1.1

> 用于个人求职作品的模拟评分标准，并非金山办公内部质检规范。涉及产品权限、会员退款、文件恢复等事实判断时，应以经核实且有日期的官方资料为准；无法核实的内容标记为“待核实”，不得自行推断。

## 一、适用范围

适用于文字客服对话，覆盖会员订阅、云文档同步、PDF处理、WPS AI、账号及协作权限。只根据可见对话评分；无订单后台或技术日志时，不把“尚未解决”直接等同于客服违规。

## 二、四维评分（各0—25分）

采用一致的锚点评级，再在区间内根据证据调整。评分越高表现越好。

| 分数 | 通用含义 |
| --- | --- |
| 23–25 | 行为完整、准确，几乎没有明显问题 |
| 19–22 | 总体合格，有轻微遗漏或解释不足 |
| 13–18 | 存在清晰可见的中度问题，影响体验 |
| 6–12 | 重要环节缺失、明显推诿或误导 |
| 0–5 | 严重缺失或明确严重违规 |

### 1. 用户诉求识别与问题处理

- 能复述或正确理解核心问题；必要时询问版本、设备、错误信息等。
- 提供可执行的排查、核实或升级路径；明确尚未确认的事项。
- 扣分依据：答非所问、遗漏核心诉求、重复无效回复、推诿、擅自结束。

### 2. 服务态度与沟通

- 礼貌、耐心，承认用户困扰；投诉和数据丢失情境有适度共情。
- 扣分依据：冷漠、指责、讽刺、侮辱、威胁。
- 不因客服简短就自动判定态度差，必须结合语境。

### 3. 专业准确性与表达

- 说明清晰，有步骤、条件、操作路径；区分已确认事实和猜测。
- 扣分依据：语义混乱、矛盾、明显错误或无法核实却确定性表达。
- 涉及产品政策，若缺少可信知识库依据则标“待核实”，不得臆断真实性。

### 4. 风险与流程合规

- 不索取密码/验证码，不泄露个人数据；不承诺未获证实的退款、恢复和时限。
- 对账号安全、重要文件丢失、重大投诉等问题提示适当安全处理与升级。
- 扣分依据：不当承诺、敏感信息索取、拒绝必要升级、隐私泄露。

## 三、风险与分数分开判断

- 综合分：四项相加，0—100。
- 服务质量层级（仅供趋势分析）：80—100良好，60—79待改进，0—59较差。
- `critical_violation`：单独布尔值。明显辱骂或威胁、索取账号密码/验证码、泄露敏感信息、未经核实承诺重要文件必能恢复等列为候选严重违规，人工最终确认。
- `risk_level`：高/中/低，结合严重违规标记与具体证据；不能仅通过总分阈值确定。

## 四、输出与人工复核规则

1. 四维必须恰好出现一次；分数为0—25整数；总分由程序计算。
2. 每项输出 `category`、`score`、`problem`、`evidence`、`suggestion`。
3. 证据是对话中完整连续出现的原文片段；没有证据时填写“未发现明确证据”，不得捏造。
4. 每个问题可附一个或多个统一标签；未出现的问题不得为了凑标签而输出。
5. 模型只能给建议性初判，人工可修改并记录原因；保留初判和终判两列。
6. 数据全部为合成对话，不代表真实WPS客服表现，不得在简历中描述成企业内部数据。

## 五、建议的问题标签

`答非所问`、`未解决诉求`、`无效追问`、`推诿责任`、`缺乏共情`、`态度冷漠`、`侮辱用户`、`解释不清`、`未经核实的产品说明`、`不合理承诺`、`隐私风险`、`升级处理缺失`。

## 六、质检示例

客户：我的文档同步之后不见了，能恢复吗？

客服：肯定能恢复，你不用担心，明天一定回来。

应标记未经核实的确定性承诺；若无日志和文件状态，不能认定文件实际可恢复。客服没有提供核实与升级路径，也应在问题处理维度扣分。
